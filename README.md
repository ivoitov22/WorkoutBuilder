# Workout Builder – Final Project

This project is a **Workout Builder web application** that allows users to create, customize, and organize workout routines using an intuitive **drag-and-drop interface**. Built with **HTML, CSS, JavaScript, and jQuery**, it demonstrates dynamic interactivity and client-side data handling.

---

## Features

- **Drag-and-drop functionality** to easily reorder exercises and build routines.  
- Add, remove, or edit exercises in your workout plan.  
- Responsive layout for smooth usage on desktop and tablet screens.  
- Real-time updates without page reloads using **jQuery DOM manipulation**.  
- Styled with **CSS** for a clean and user-friendly interface.

---

## Technologies Used

- **HTML** – Structure and markup of the web app  
- **CSS** – Styling and responsive design  
- **JavaScript & jQuery** – Interactive behavior and drag-and-drop functionality  
- **jQuery UI (optional)** – For drag-and-drop and sortable lists
